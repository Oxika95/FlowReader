#
# TTS-oriented English non-breaking prefixes for sentence boundary detection.
#
# Intentionally a tiny subset of the Lingua::Sentence / mediacloud list.
# Missing a real sentence end hurts spoken clips more than occasionally
# splitting on Inc. / St. / initials. See NOTICE.md for attribution.
#
# Anything listed here, followed by a period and an upper-case word, does NOT
# indicate an end-of-sentence marker. Prefixes marked #NUMERIC_ONLY# only
# suppress a break when the next token starts with a digit.
#

# Titles commonly followed by a capitalized name
Mr
Mrs
Ms
Dr
Prof
Sr
Jr

# Latin abbreviations that often precede examples / restatements
e.g
i.e

# "No. 5" stays attached; "No. That…" may still break
No #NUMERIC_ONLY#
