# Couplings

Lists the places where one change has to be matched by another: shared flows and keys, call orders, locks,
file layouts, tuned constants. Phase 2 wrote the wave-1 lines (share and import, settings overlay, plugin
sync, startup seeding); until the rest are written, `scripts/seams-allow.txt` holds every item that
`scripts/agent/seams-check.mjs` finds in the code and that isn't written here yet.

Format: `- <kind>: <name> [rg: <pattern>] -> <files>; <note>`. The file list after `->` is filled in by
`node scripts/agent/seams-check.mjs --write`. Lines without `[rg: ...]` are hand-written. Search with
`rg -n "<FileName>" docs/agent/seams.md` to get every coupling a file takes part in.
